# Contracts

This directory contains the canonical JSON Schemas for the GridPilot project.

**Discipline:**
Contracts are frozen. They represent the exact shape of the data that passes between the optimizer, backend, and dashboard. Changes to these schemas must be heavily scrutinized to maintain backwards compatibility. Additive changes are allowed after Phase 1, but existing fields are never renamed or removed.

See `docs/architecture/API_CONTRACT.md` for more details.
