# Vybe-grid

## Microgrid Energy Mix Optimizer

A renewable energy intelligence platform that optimizes
the energy mix for off-grid communities.

### Team
Vybe

### Theme
Renewable Energy Intelligence

### Problem Statement
Optimize solar, wind, battery storage, and diesel
backup to minimize cost and emissions while maintaining
reliable power supply.

### Tech Stack
- Backend: Python + FastAPI
- Frontend: React
- Database: PostgreSQL
- Optimization: Python
- Weather API: Open-Meteo

🚧 Under Development
